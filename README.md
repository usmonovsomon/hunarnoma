# Rohnamo — Career & Education Discovery Platform


> **Rohnamo** (тадж. *роҳнамо* — «проводник»). Помогает школьникам и абитуриентам
> Центральной Азии пройти путь **«от „не знаю, кем стать“ → до „я поступаю сюда“».**

Это работающий прототип продукта на **Next.js 14 (App Router) + TypeScript + Tailwind CSS**,
реализующий ядро концепции: связанный граф **профессия → направление → университет**,
профориентационный тест и персональный план «Мой путь».

Полная продуктовая концепция (Product Discovery): [`docs/BLUEPRINT.md`](docs/BLUEPRINT.md).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Прочие команды: `npm run build`, `npm start`, `npm run typecheck`.

## Что реализовано

Все маршруты живут под префиксом локали: `/ru/…`, `/tj/…`, `/en/…`.

| Раздел | Маршрут | Суть |
|---|---|---|
| Главная | `/[locale]` | Hero + развилка «знаешь, кем стать?», шаги, популярные профессии, 5 кластеров, популярные направления |
| Профессии | `/[locale]/professions`, `/[locale]/professions/[slug]` | Пилотный каталог 19 профессий (7 своих сфер — IT, инженерия, медицина, бизнес, право, образование, медиа), с поиском/фильтрами + страница профессии: чем занимается, навыки, профильные предметы, плюсы/минусы, **какие направления к ней ведут** (ссылки на реальные специальности из датасета НЦТ) |
| Направления | `/[locale]/specialties`, `/[locale]/specialties/[code]` | Каталог 646 специальностей с поиском/фильтрами + страница направления: что изучают, кем работать, профильные предметы, **где учат** (все вузы с местами, ценой, языком, формой) |
| Кластеры | `/[locale]/clusters/[slug]` | 5 официальных кластеров НЦТ: описание, профильные предметы, все направления кластера |
| Университеты | `/[locale]/universities`, `/[locale]/universities/[slug]` | Каталог 42 вузов (поиск, регион, тип) + профиль: контакты (**телефоны — кликабельные `tel:`**) и все направления по кластерам с местами и ценой |
| Профориентация | `/[locale]/career-test`, `/[locale]/career-test/result` | Explainable-тест: интересы → топ кластеров с объяснением «почему» + примеры направлений |

## Локализация

Три языка: **русский (`/ru`), таджикский (`/tj`), английский (`/en`)**.

- `middleware.ts` перенаправляет запрос без префикса на локаль: сначала cookie
  `rohnamo_locale`, затем `Accept-Language`, иначе `ru`. Выбор языка запоминается в cookie.
- Переключатель в шапке (`components/LocaleSwitcher.tsx`) меняет только сегмент локали —
  посетитель остаётся на той же странице.
- В `<head>` проставляются `canonical` и `hreflang` (`ru` / `tg` / `en` / `x-default`),
  `<html lang>` — `ru` / `tg` / `en`. Каждая локаль индексируется отдельно.
- Числа форматируются под локаль; множественное число — своё правило на язык
  (`plural()` в `lib/i18n`): 3 формы для русского, 2 для английского, а в таджикском
  существительное после числительного не изменяется.

### Что где лежит

```
lib/i18n/config.ts            — список локалей, htmlLang/Intl-теги, разбор Accept-Language
lib/i18n/index.ts             — getDict, fmt (подстановка {x}), plural, форматы чисел, href
lib/i18n/dictionaries/ru.ts   — эталонный словарь: его тип Dict проверяет tj.ts и en.ts,
                                 поэтому забытый ключ — ошибка компиляции, а не пустая строка
lib/i18n/content/{ru,tj,en}   — редакционные тексты: кластеры + описания направлений
lib/i18n/data.ts              — локализованные имена из датасета + чистка поля «язык обучения»
data/i18n/specialties.{tj,en}.json   — 598 названий специальностей (ключ — русское название)
data/i18n/universities.{ru,tj,en}.json — названия и аббревиатуры 42 вузов
```

Любой перевод, которого нет, деградирует до русского оригинала, а не до пустоты.

### Добавить язык

1. Добавить код в `LOCALES` и `LOCALE_META` (`lib/i18n/config.ts`).
2. Создать `lib/i18n/dictionaries/<код>.ts` — тип `Dict` подскажет все обязательные ключи.
3. Создать `lib/i18n/content/<код>.ts` и зарегистрировать в `lib/i18n/content/index.ts`.
4. При необходимости — `data/i18n/specialties.<код>.json` и `universities.<код>.json`.

## Источники данных

Все данные — **официальные, из плана приёма Национального центра тестирования при
Президенте РТ (ntc.tj) на 2026–2027 учебный год.**

- **Университеты (42), специальности (646) и программы приёма (3474)** извлечены из
  официальных PDF по 5 кластерам (`scripts/parse_ntc.mjs`, парсинг `pdftotext -table` +
  сопоставление вузов) и собраны в единый датасет (`scripts/build_data.mjs` → `lib/ntc/data.json`).
  Каждая программа несёт реальные поля: вуз, город, форма обучения, платно/бесплатно,
  **стоимость в сомони**, язык обучения и число мест.
- **Описания «что это за профессия и что изучают»** источник не содержит — они добавлены
  вручную для популярных направлений (`lib/i18n/content/*`). Фактические цифры всегда берутся
  из данных, тексты — только пояснительные.
- **Каталог профессий** (`/professions`, `lib/professions/*`, `lib/i18n/professions/*`) — тем более
  редакционный слой: план приёма НЦТ не содержит понятия «профессия» вообще. Список 19 профессий,
  их сферы и текстовые описания придуманы и написаны вручную; связь с реальными направлениями
  (`specialtyCodes`) — единственное, что проверено по датасету. Никаких цифр зарплаты/спроса
  не показывается — только качественное описание, чтобы не выдавать выдумку за факт.
- **Переводы названий** источник тоже не содержит: план приёма выпущен только по-русски.
  Названия 598 специальностей и 42 вузов на tj/en — редакционный перевод
  (`data/i18n/*`), а не официальная номенклатура. Для документов сверяйтесь с
  русским оригиналом на ntc.tj.

### Известные артефакты парсинга PDF

Извлечение из PDF местами захватывает соседние колонки — это видно в самих данных:

- Поле «язык обучения» испорчено у 63 из 3474 программ (значения вида
  `таджикский, платный (3850) таджикский 17`). Из-за агрегации по вузу это задевало
  19 из 42 профилей. UI больше это не показывает: `parseLanguages()`
  (`lib/i18n/data.ts`) оставляет только реальные языки — таджикский, русский,
  английский, узбекский. **Сами данные не исправлены** — чинить нужно в парсере.
- `shortName` вузов был обрезан до одной буквы (`Т`, `И`, `Д`, `Х`) и дублировался
  (`ИТХ`, `МТ`, `ГТ`, `ФНД` — по два раза). Исправленные аббревиатуры лежат в
  `data/i18n/universities.ru.json` — тоже надстройка над данными, не правка датасета.
- Часть названий специальностей обрезана или несёт мусорный хвост
  (`Металлургия гического`, `(СФИТБНТУиТТУ)`, `(ТЭилиЭСН)`). В tj/en такие хвосты
  опущены, обрезанные названия переведены как есть.

### Обновление данных

```bash
# скачать свежие PDF кластеров с ntc.tj в data/raw/, затем:
npm run data      # парсинг PDF → data/parsed/*.json → lib/ntc/data.json
```

Названия специальностей в PDF переносятся по строкам и иногда «слипаются» с текстом
вуза. Чистка имён — двухслойная: правки-реконструкции в `data/name_overrides_auto.json`
(генерируются `scripts/gen_name_overrides.mjs`) и точечные ручные правки в
`NAME_OVERRIDES` внутри `scripts/parse_ntc.mjs` (ручные имеют приоритет).

## Ключевые архитектурные решения

- **Связь — это продукт.** Профессия ↔ направление ↔ университет смоделированы явно
  (`lib/types.ts`), различия сущностей разведены (см. BLUEPRINT §8).
- **Достоверность данных — фундамент.** У изменчивых данных есть `Source`
  (`label / updatedAt / verified`), в UI — бейджи и «проверьте на офиц. сайте».
  Числовые данные вузов (цена, баллы, места) не входят в API и помечены как требующие проверки.
- **Объяснимый рекомендатель без ML** (`lib/test.ts`): прозрачный скоринг + «почему».

## Структура

```
middleware.ts      — редирект на локаль (cookie → Accept-Language → ru)
app/[locale]/      — все страницы (App Router); здесь же root layout с <html lang>
components/        — Nav, Footer, LocaleSwitcher, карточки, каталоги (client), UI-примитивы
lib/i18n/          — локали, словари, редакционный контент, локализованные имена из датасета
lib/phone.ts       — разбор телефонов НЦТ → кликабельные `tel:+992…`
lib/ntc/index.ts   — типы + загрузка датасета + агрегации и хелперы
lib/ntc/data.json  — собранный датасет (вузы, направления, программы, статистика)
lib/ntc/content.ts — структура кластеров (emoji, цвет) + типы редакционного слоя
lib/test.ts        — модель скоринга «интересы → кластеры» (тексты вопросов — в словарях)
scripts/           — parse_ntc.mjs (PDF → JSON), build_data.mjs (JSON → датасет)
data/i18n/         — переводы названий специальностей и вузов
data/raw/          — исходные PDF НЦТ; data/parsed/ — промежуточный JSON
docs/BLUEPRINT.md  — полный Product Discovery
```

## Телефоны

Номера в плане приёма записаны в местном формате, а одно поле может содержать
несколько номеров — через запятую **или просто через пробел**
(`(44) 600-39-12 (44) 600-39-77`). `parsePhones()` (`lib/phone.ts`) разбирает поле на
отдельные номера и нормализует каждый в `tel:+992XXXXXXXXX`; на экране остаётся
привычная запись `(44) 600-39-12`. Все 42 вуза разбираются без остатка; если номер
почему-то не приводится к 9 цифрам, он отображается обычным текстом, а не битой ссылкой.

## ⚠️ О данных

Цифры (стоимость, места, язык, форма) — из **официального плана приёма НЦТ 2026–2027** и
верны на момент публикации плана. Стоимость платного обучения и число мест вуз может менять —
перед подачей документов уточняйте на приёмной комиссии. Пояснительные описания направлений —
редакционные (ориентир), не официальный источник. Переводы названий специальностей и
вузов на таджикский и английский — тоже редакционные: официальных версий плана приёма
на этих языках нет.
